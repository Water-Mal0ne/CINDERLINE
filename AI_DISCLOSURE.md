# AI disclosure

Codex assisted with project planning, implementation, statistical safeguards, Python and TypeScript code generation, tests, documentation, and submission drafts. Parallel agents worked on data/harmonization, rhythm/scientific tests, and the web interface; the coordinating agent integrated and checked the result.

The second phase used separate agents for the globe/calendar, comparison, seasonal context, and anomaly explorer, followed by an independent release-quality agent. Codex wrote the 3D renderer and annual-grid aggregation. Its heatmap values come from processed NASA observations using the documented calibration; they are not generated imagery or invented measurements. Natural Earth supplies the land and border geometry.

NASA FIRMS observations are external scientific source data, not AI-generated data. Synthetic fixtures are programmatically generated, visibly labeled, and kept separate from real observations. No AI-generated imagery, audio or video is included in this build. No NASA logo is used and no NASA endorsement is implied.

Model outputs and interpretations require human team review before submission. Retain this disclosure in the project description and repository; update it if additional AI tools or generated media are used.
