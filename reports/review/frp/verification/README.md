# Independent FRP verification

This directory is generated by `scripts/verify_frp_test.py`. The checker imports no functions from the main FRP analysis. It independently reads the existing clean caches, verifies raw-archive and aggregate provenance, checks local timestamps using the stored IANA zones, reconstructs daily counts and FRP sums, and reproduces both masks, annual indices, shared bootstrap draws and robustness gates.

The portable scripts reproduce an already-known outcome. The original local protocol was frozen at **2026-11-14 18:57:23.284 UTC**, before the first FRP contrasts were calculated. Git receipt `92626ed2f76fc6ab1bcefa6254d49609b7c6b982` was committed **after** the outcome; neither this verification nor that commit is a new prediction or external preregistration.

From the repository root, after running the main analysis:

```sh
python scripts/verify_frp_test.py --data-root /path/to/existing/firetrace/data/processed/clean_cache_v2 --report-dir reports/review/frp
python scripts/plot_frp_test.py --report-dir reports/review/frp
```

`--data-root` may also name the existing source repository. The source tree must retain the raw country archives, cleaned caches, `work/phase3/nepal-us/source_manifest.json`, and matching count partitions. No files are downloaded and no scientific source cache is overwritten. The checker stops when inputs cannot be verified.

Read `../independent_verification.json` for the portable verification verdict and official daytime-count reconciliation; `input_audit.json` for source/filter/time checks; `independent_data_gate.json` for both-mask FRP quality; and `agreement.json` for the complete numerical comparison. `independent_results.json` contains the separately calculated scientific verdict, including the Terra result. CSVs retain all annual weekday profiles, omissions, maximum-day removals and eligibility counts.

The full seven-day figure is generated from the checked annual profiles, using equal weight for each year. Only the Sunday comparison is the prespecified test. Both metrics use the same valid-FRP detections. All retained values in this dataset are valid, so ordinary counts and paired counts happen to coincide.

This verifies computational reproducibility, not ground-truth fire activity or causal interpretation. Stored timezone labels are checked against their timestamp conversions; the checker does not independently rebuild coordinate-to-timezone boundaries. Calendar eligibility is not cloud-free observation exposure. Twelve annual resampling blocks and correlated satellite streams remain limitations. Summed FRP is sampled radiative power, not energy, emissions, burned area or fire counts.
