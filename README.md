# CINDERLINE

Two satellites. One unbroken fire record.

CINDERLINE is a web app that converts MODIS and VIIRS hotspot records to a named Aqua reference scale, so users can compare historical burning activity across a change of instrument. It provides calendars, area selection and evidence for each estimate, alongside a separate weekly-rhythm analysis of the raw satellite streams.

[Open the site](https://cinderline-spaceapps.pages.dev/) | [Earlier calendar screenshot](submission/assets/live-calendar.jpg)

Team: NASA Space Apps 2026, Kathmandu, Nepal local event.

The calendar covers seven countries and extends through 2025; the main conversion evaluation ends in 2024. Hotspots are detections, not distinct burning events. The calendar is historical, not a forecast or warning. "Unbroken" describes the shared reference scale, not uninterrupted observation coverage: outages remain visible.

The repository also includes a separate [2024 observed-hotspot layer](docs/02-user-guide.md#satellite-observations) for closer Earth inspection across all seven countries. It is not yet deployed to the live site above.

## Run locally

From a clone of this repository, with Node.js and npm installed:

```sh
npm ci --prefix web
npm --prefix web run dev
```

Open the local URL printed by Vite. The committed data are sufficient; no archive download is needed. `npm --prefix web test` runs web tests. `npm run build` type-checks the app and creates `dist/`. Python setup, source-file requirements and scientific rebuild commands are in the reproduction guide.
